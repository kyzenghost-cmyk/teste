# Teste App

Este é um aplicativo de exemplo simples que exibe uma página web estática usando Node.js e Express.

## Como executar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor:
   ```bash
   node app.js
   ```
3. Abra o navegador em `http://localhost:3000`.

## Estrutura

- `app.js` – servidor Express
- `public/index.html` – página estática
- `package.json` – dependências do projeto
